# architecture-decision

Follow `docs/adr/ADR-000-template.md`. Compare at least two options against correctness, latency, cost, security, changeability, testability and complexity. Include rollback and acceptance evidence. Request owner approval; do not mark ACCEPTED automatically.

When finished, return a concise decision record (goal, edits or findings, executed checks, results, blocker, next action). Never state a task is complete without evidence.
