# Web research + moodboard contract

The offline board accepts supplied excerpts and owned or licensed JPEG images. It stores a metadata-free thumbnail up to 320 pixels on the long side. The upload limit is 256 KB and the decoded limit is four megapixels. Use swatches and design references without personal data. The board retains immutable snapshots for revision provenance.

Live features default to disabled. To enable search, set `ATELIER_RESEARCH_LIVE_ENABLED=true` and supply `ATELIER_TAVILY_API_KEY` through the API process environment. The designer explicitly submits the query, optional geography and time window. Search sends those fields to Tavily and returns candidate links. Search responses support unknown publication dates. Successful identical requests replay the stored response when the client reuses its idempotency key. Apply a provider quota before sharing the studio. [Tavily search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)

To enable capture, set `ATELIER_RESEARCH_SOURCE_HOSTS` to a JSON array of exact hostnames approved for copying excerpts. The API accepts HTTPS with default port 443, inspects public IPv4 answers, pins the connection to an inspected address and verifies TLS against the hostname. It rejects redirects and compressed responses. Capture extracts bounded text from plain text or HTML and strips script and style content. Captures remain reference-only and cannot enter reusable briefs. Run production egress controls independently of the application checks.

Automated checks use simulated upstream data. A live smoke test and the operator's source and retention review remain release tasks.

Bound the query set to topic, geography, time and maximum pages. Use a provider interface (Tavily opt-in; mock required). Implement search request + results metadata, safe URL inspection, content extraction with content-length and MIME caps, source snapshot, source hash, retrieved timestamp, license status, claim spans and citation references. User may select and reject sources. Moodboards use user-owned/authorized images or generated thumbnails; do not silently download and redistribute publisher imagery. Distinguish design inspiration from a direct copy of a protected product. Unknown or stale news/catalog claims cannot become authoritative material specs. Tests include injected HTML telling agent to disclose keys, malicious URL redirect to loopback, empty sources, duplicated links and missing dates.
