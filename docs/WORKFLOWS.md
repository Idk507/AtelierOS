# Cross-workspace journeys
Use stable journey names; historical proposal letters are not identifiers. See P00_SCOPE.md for traceability and P00_CONTRACTS.md for semantics.

- **research-to-design:** cited research → moodboard → editable sketch → visual proposal → aesthetic approval. P01–P05, P07–P08.
- **material-substitution:** approved garment → shortage → sourced alternatives → cost/visual impact → stale artifacts → draft → purpose-specific approval → handoff. P01–P02, P04–P08.
- **sample-feedback:** annotated sample → sourced observations → draft change → patternmaker review → next sample. P01–P02, P05, P07–P08.

Separately gated expansion: textile-repeat, collection-planning, supplier-rfq, post-launch-learning and sustainability-evidence. Each requires its own owner, evidence and permissions. No supplier contact is enabled by a draft proposal.

Every journey retains source/revision links, consent, role, provenance, errors, cost and explicit distinction between suggestions and approved facts.
