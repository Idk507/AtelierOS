# P08 — Pilot hardening and release gate

Status: NOT STARTED. This is a proposed phase contract, not implemented functionality.

## Objective
Comprehensive end-to-end journey tests, usage quotas, security controls, logging/traces, PII retention, cost dashboards, developer runbook and staging deployment. Pilot only with consent.

## Required outputs
Deployment manifests, operator runbook, evaluated benchmark results, manual rollout/rollback and demo recording instructions.

## Implementation sequence
1. Verify only the relevant ADRs and previous phase gate. Identify existing code to reuse.
2. Define Pydantic/TypeScript request/response contracts and failure cases before integration.
3. Write offline test fixtures and negative tests; implement smallest vertical slice.
4. Add authorization, provenance, revision checks, idempotency, tracing and cost telemetry where relevant.
5. Run focused tests, record command/output and report blockers.
6. Update `docs/STATUS.md` and request architect sign-off before progressing.

## Acceptance gate
No critical auth issues, acceptable measured performance, designer acceptance captured, deploy approval explicit and traceability of all dependencies.

## Stop conditions
Stop for review on any missing model deployment, external permission, license question, unknown data provenance, irreversible migration, unapproved cost, weakened security rule or unsupported technical claim. Do not silently substitute fake successes.

## Review artifact
A concise PR summary with files changed, contract diffs, tests passed/failed/skipped, screenshot/artifact evidence, threat updates, cost exposure and explicit pass/fail decision. No broad speculative scaffolding beyond this phase.
